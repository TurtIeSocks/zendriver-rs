1//! In-page evaluators, templated from [`TurnstileSelectors`].
2//!
3//! Three scripts run against the page's main world, and every one of them is
4//! built here from the caller's markers rather than from literals. That is
5//! the point of the module: before it existed the Cloudflare hostname was
6//! written out twice, in the poll evaluator and in a separate detector
7//! script, and the two could drift.
8//!
9//! Each script is composed as *one IIFE* by [`main_world_expr`]. That is a
10//! stealth requirement, not formatting. `Runtime.evaluate` with no
11//! `contextId` runs a classic script in the page's main world, where a
12//! top-level `function foo() {}` becomes a property of the global object —
13//! so an unwrapped walker publishes `window.findChallengeIframe` and
14//! `window.clickableRect` to the page on every poll tick, names belonging to
15//! an automation library sitting in the same realm as the challenge script.
16//! Inside the IIFE they are ordinary locals.
17//!
18//! # JavaScript style
19//! Injected scripts declare with `var` and iterate with indexed loops, never
20//! `for...of`. `for...of` over a `NodeList` enters through
21//! `NodeList.prototype[Symbol.iterator]`, a writable, configurable property
22//! the page can redefine to watch someone walk its DOM. That one is worth
23//! declining: it is a single chokepoint, entered once per loop and then
24//! driven by one `next()` per element, and a handler installed there can
25//! read `new Error().stack` and filter the page's own iteration out of what
26//! it collects. An indexed loop never reaches it.
27//!
28//! It buys that one signal and no more. Indexed access is *not*
29//! unobservable: `NodeList.prototype.length` is a WebIDL accessor with
30//! `configurable: true`, so a page can wrap the getter, delegate to the
31//! original, and count every read with nothing of its own broken. The rest
32//! of the walk is louder. Each tick calls `root.querySelectorAll("iframe")`
33//! and then `root.querySelectorAll("*")`, both ordinary writable methods on
34//! `Document` / `Element` / `DocumentFragment`, and the iframe test calls
35//! `String.prototype.includes` — equally patchable — with the marker the
36//! walker is hunting for. A hook there is handed that marker, which is a
37//! sharper tell than the iterator hook this convention avoids.
38//!
39//! Measured on Chrome 151 with all four wrapped: the walk still returns the
40//! right iframe, while the page observes both `querySelectorAll` selectors,
41//! every `length` read and that marker, against zero `Symbol.iterator`
42//! calls. So the convention removes one signal from a loop that stays
43//! observable to a page that looks for it; it is not cover. This is a rule
44//! about declarations and iteration only — modern methods are used freely,
45//! since declining them would buy nothing either.

49/// Render `value` as a JavaScript string literal, escaped.
50///
51/// Mandatory rather than cosmetic: the default token selectors contain
52/// double quotes (`[name="cf-turnstile-response"]`), so naive interpolation
53/// terminates the literal early and injects whatever follows. JSON string
54/// syntax is a subset of JavaScript's, and serializing a `&str` cannot fail
55/// — the fallback is unreachable and exists only to keep this total.
56fn js_string(value: &str) -> String {
57    serde_json::to_string(value).unwrap_or_else(|_| "\"\"".to_string())
58}
59
60/// Render `values` as a JavaScript array-of-strings literal. Same escaping
61/// argument as [`js_string`].
62fn js_string_array(values: &[String]) -> String {
63    serde_json::to_string(values).unwrap_or_else(|_| "[]".to_string())
64}

66/// Shared prelude for every evaluator below. Declares:
67///
68/// - `findChallengeIframe(root)` — the first iframe reachable from `root`
69///   whose `src` contains
70///   [`iframe_src_contains`](TurnstileSelectors::iframe_src_contains),
71///   descending into open shadow roots (Cloudflare sometimes hosts the
72///   widget inside one), else null. An **empty** marker returns null
73///   without walking anything: `"".includes("")` is true, so an unguarded
74///   walk would hand back the page's first `src`-carrying iframe and the
75///   driver would scroll to it and click it.
76/// - `clickableRect(el)` — `el`'s viewport rect *only if it is a real click
77///   target*: non-zero size and not hidden by `visibility` / `display` /
78///   `opacity`. A zero-size or hidden iframe is not a target — invisible
79///   Turnstile mounts a 0×0 iframe whose token is populated with no click,
80///   and clicking it would dispatch mouse events at a meaningless point.
81///
82/// Never evaluated on its own; [`main_world_expr`] wraps it.
83fn walker_js(selectors: &TurnstileSelectors) -> String {
84    let marker = js_string(&selectors.iframe_src_contains);
85    format!(
86        r#"
87var IFRAME_MARKER = {marker};
88function findChallengeIframe(root) {{
89    if (!IFRAME_MARKER) return null;
90    var iframes = root.querySelectorAll ? root.querySelectorAll("iframe") : [];
91    for (var i = 0; i < iframes.length; i++) {{
92        var f = iframes[i];
93        if (f.src && f.src.includes(IFRAME_MARKER)) return f;
94    }}
95    var all = root.querySelectorAll ? root.querySelectorAll("*") : [];
96    for (var j = 0; j < all.length; j++) {{
97        if (all[j].shadowRoot) {{
98            var sub = findChallengeIframe(all[j].shadowRoot);
99            if (sub) return sub;
100        }}
101    }}
102    return null;
103}}
104function clickableRect(el) {{
105    if (!el) return null;
106    var r = el.getBoundingClientRect();
107    if (!(r.width > 0 && r.height > 0)) return null;
108    var view = el.ownerDocument && el.ownerDocument.defaultView;
109    var style = view && view.getComputedStyle ? view.getComputedStyle(el) : null;
110    if (style && (style.visibility === "hidden" || style.display === "none" || style.opacity === "0")) {{
111        return null;
112    }}
113    return {{ x: r.left, y: r.top, width: r.width, height: r.height }};
114}}
115"#
116    )
117}

119/// Compose the in-page source for `body`: the walker and `body` together
120/// inside a single IIFE, whose completion value is whatever `body` returns.
121/// See the module docs for why the wrapper is load-bearing.
122pub(crate) fn main_world_expr(selectors: &TurnstileSelectors, body: &str) -> String {
123    let walker = walker_js(selectors);
124    format!("(function(){{{walker}{body}}})()")
125}

127/// The unified poll evaluator. Returns, in one round-trip:
128/// - `token` — the first non-empty value among
129///   [`token_inputs`](TurnstileSelectors::token_inputs), else null.
130/// - `bbox` — the challenge iframe's rect when it is a valid click target,
131///   else null.
132/// - `hasMarkers` — true when *any* marker is present: the container, a
133///   token input, or the challenge iframe (visible or not).
134///
135/// The token input is in light DOM by design (page JS reads it to submit
136/// forms), so `document.querySelector` is sufficient there.
137pub(crate) fn poll_expr(selectors: &TurnstileSelectors) -> String {
138    let container = js_string(&selectors.container);
139    let token_selectors = js_string_array(&selectors.token_inputs);
140    main_world_expr(
141        selectors,
142        &format!(
143            r#"
144    var iframe = findChallengeIframe(document);
145    var bbox = clickableRect(iframe);
146    var tokenSelectors = {token_selectors};
147    var input = null;
148    for (var k = 0; k < tokenSelectors.length && !input; k++) {{
149        if (tokenSelectors[k]) input = document.querySelector(tokenSelectors[k]);
150    }}
151    var token = (input && input.value) ? input.value : null;
152    var containerSelector = {container};
153    var hasContainer = containerSelector ? !!document.querySelector(containerSelector) : false;
154    var hasMarkers = hasContainer || !!input || !!iframe;
155    return {{ token: token, bbox: bbox, hasMarkers: hasMarkers }};
156"#
157        ),
158    )
159}

161/// The scroll-and-measure evaluator. Brings the challenge iframe fully into
162/// the viewport when it isn't already, then returns its *post-scroll* rect —
163/// or null if the widget vanished or is not a valid click target.
164///
165/// `behavior: "instant"` is load-bearing: the default `"auto"` resolves to
166/// the element's computed `scroll-behavior`, so on a page setting
167/// `html { scroll-behavior: smooth }` the scroll animates and the
168/// `clickableRect` call on the next synchronous line reads the *pre*-scroll
169/// rect — the one thing this round-trip exists to avoid.
170pub(crate) fn scroll_expr(selectors: &TurnstileSelectors) -> String {
171    main_world_expr(
172        selectors,
173        r#"
174    var iframe = findChallengeIframe(document);
175    if (!iframe) return null;
176    var r = iframe.getBoundingClientRect();
177    var vw = window.innerWidth || document.documentElement.clientWidth;
178    var vh = window.innerHeight || document.documentElement.clientHeight;
179    var fullyVisible = r.top >= 0 && r.left >= 0 && r.bottom <= vh && r.right <= vw;
180    if (!fullyVisible && iframe.scrollIntoView) {
181        iframe.scrollIntoView({ block: "center", inline: "center", behavior: "instant" });
182    }
183    return clickableRect(iframe);
184"#,
185    )
186}

188/// The presence detector. Returns the challenge iframe's raw rect if one is
189/// mounted at all, else null.
190///
191/// Deliberately a different question from [`poll_expr`]'s `bbox`: this
192/// reports a *mounted* iframe, that one reports a *clickable* one. A 0×0
193/// invisible-Turnstile iframe is mounted but must never be clicked.
194pub(crate) fn detect_expr(selectors: &TurnstileSelectors) -> String {
195    main_world_expr(
196        selectors,
197        r#"
198    var iframe = findChallengeIframe(document);
199    if (!iframe) return null;
200    var r = iframe.getBoundingClientRect();
201    return { x: r.left, y: r.top, width: r.width, height: r.height };
202"#,
203    )
204}

258    /// An empty `iframe_src_contains` must not mean "match every iframe".
259    /// `String.prototype.includes("")` is true for every string, so an
260    /// unguarded walk hands back the page's first `src`-carrying iframe —
261    /// whatever it is — and the driver then scrolls to it and clicks it.
262    /// The other two markers already read empty as "signal off"
263    /// (`container` is guarded in [`poll_expr`], empty `token_inputs`
264    /// entries are skipped), so this one does too.
265    ///
266    /// Asserted against the source rather than by running it: these tests
267    /// have no JS engine. Presence alone would not be enough — a guard
268    /// placed after the walk guards nothing — so the assertion is on where
269    /// it sits.
270    #[test]
271    fn an_empty_iframe_marker_matches_no_iframe_rather_than_every_one() {
272        const GUARD: &str = "if (!IFRAME_MARKER) return null;";
273        let src = poll_expr(&TurnstileSelectors {
274            iframe_src_contains: String::new(),
275            ..TurnstileSelectors::default()
276        });
277        let guard = src
278            .find(GUARD)
279            .expect("an empty marker must short-circuit the walk");
280        let walk = src
281            .find(r#"querySelectorAll("iframe")"#)
282            .expect("the walk itself went missing");
283        assert!(
284            guard < walk,
285            "the empty-marker guard must precede the walk it guards"
286        );
287    }

349    /// Names every declaration in `src` at `{}` depth 0 that a classic
350    /// script publishes on the page's global object: `var` and *named*
351    /// `function`. Both become enumerable `window` properties (verified on
352    /// Chrome 151); `let` / `const` / `class` are script-scoped and never
353    /// do, so they are not leaks and are not counted. An anonymous
354    /// `function (` — the IIFE wrapper itself — is an expression and binds
355    /// nothing.
356    ///
357    /// Brace counting is only sound because no injected source puts a brace
358    /// inside a string literal. Keep it that way; the alternative is a JS
359    /// parser for a cookie-name-sized job. That now includes caller-supplied
360    /// selectors, which is why the fixtures here use quotes and backslashes
361    /// rather than braces. Comment text is scanned like any other, which can
362    /// only ever produce a loud false positive, never a silent pass.
363    fn top_level_page_globals(src: &str) -> Vec<String> {
364        let is_ident = |c: char| c.is_alphanumeric() || c == '_' || c == '$';
365        let mut found = Vec::new();
366        let mut depth = 0i32;
367        for (i, ch) in src.char_indices() {
368            match ch {
369                '{' => depth += 1,
370                '}' => depth -= 1,
371                _ => {}
372            }
373            if depth != 0 {
374                continue;
375            }
376            // A keyword that is really the tail of a longer identifier
377            // declares nothing: `myvar`, `refunction`.
378            if src[..i].chars().next_back().is_some_and(is_ident) {
379                continue;
380            }
381            for keyword in ["function", "var"] {
382                let Some(rest) = src[i..].strip_prefix(keyword) else {
383                    continue;
384                };
385                // `var` needs a separator to be a declaration. `function`
386                // does not: `function(` is an expression, and the empty-name
387                // check below is what rejects it.
388                if keyword == "var" && !rest.starts_with(char::is_whitespace) {
389                    break;
390                }
391                let name: String = rest
392                    .trim_start()
393                    .chars()
394                    .take_while(|c| is_ident(*c))
395                    .collect();
396                if !name.is_empty() {
397                    found.push(name);
398                }
399                break;
400            }
401        }
402        found
403    }

405    /// The leak guard has to be able to fail. Fed the pre-fix shape — the
406    /// walker evaluated beside the IIFE rather than inside it — it must name
407    /// the declaration; fed the shipped shape it must stay quiet. The `var`
408    /// case is here because the scan is named for page globals, and a
409    /// top-level `var` is one just as much as a `function` is.
410    #[test]
411    fn top_level_scan_catches_every_leaked_page_global() {
412        assert_eq!(
413            top_level_page_globals(
414                "function findChallengeIframe(root) { return null; }\n(function(){ return 1; })()"
415            ),
416            vec!["findChallengeIframe".to_string()],
417        );
418        assert_eq!(
419            top_level_page_globals("var iframes = document.querySelectorAll('iframe');"),
420            vec!["iframes".to_string()],
421            "a top-level `var` is a `window` property too"
422        );
423        assert!(
424            top_level_page_globals("(function(){ function nested(){} var local = 1; })()")
425                .is_empty(),
426            "a declaration inside the wrapper is a local, not a global"
427        );
428        // Script-scoped forms never reach `window`, so flagging them would
429        // be a false positive, and a keyword inside a longer identifier is
430        // not a keyword at all.
431        assert!(
432            top_level_page_globals("let a = 1; const b = 2; class C {}\nvarnish.myvar = 3;")
433                .is_empty(),
434        );
435    }

437    /// `Runtime.evaluate` with no `contextId` runs a classic script in the
438    /// page's main world, where a top-level `function foo() {}` or `var bar`
439    /// becomes `window.foo` / `window.bar`. Publishing `findChallengeIframe`
440    /// / `clickableRect` there hands the challenge script — same realm,
441    /// actively looking — a pair of names belonging to an automation
442    /// library, on every poll tick. Every source this crate injects keeps
443    /// its helpers and its locals inside a function scope.
444    #[test]
445    fn injected_sources_declare_no_page_globals() {
446        let sel = TurnstileSelectors::default();
447        for (name, src) in [
448            ("poll evaluator", poll_expr(&sel)),
449            ("scroll evaluator", scroll_expr(&sel)),
450            ("detect evaluator", detect_expr(&sel)),

453            assert!(
454                leaked.is_empty(),

467    /// `scrollIntoView`'s default `behavior: "auto"` resolves to the
468    /// element's computed `scroll-behavior`, so on a page setting
469    /// `html { scroll-behavior: smooth }` the scroll animates and the
470    /// `clickableRect` call on the next synchronous line reads the
471    /// *pre*-scroll rect — the one thing this extra round-trip exists to
472    /// avoid, leaving the click aimed outside the viewport.
473    #[test]
474    fn scroll_evaluator_pins_instant_scroll_behavior() {
475        const CALL: &str = "scrollIntoView(";
476        let src = scroll_expr(&TurnstileSelectors::default());
477        let mut calls = 0;
478        for (idx, _) in src.match_indices(CALL) {
479            let after = &src[idx + CALL.len()..];
480            let end = after.find(')').expect("unterminated scrollIntoView call");
481            let args = &after[..end];
482            assert!(
483                args.contains(r#"behavior: "instant""#),
484                "scrollIntoView({args}) leaves behavior to the page's computed scroll-behavior"
485            );
486            calls += 1;
487        }
488        assert_eq!(calls, 1, "expected one scrollIntoView call to guard");
489    }
