1//! Chromium binary downloader.
2//!
3//! See the [Fetcher chapter](https://turtiesocks.github.io/zendriver-rs/fetcher.html)
4//! of the [zendriver-rs user guide](https://turtiesocks.github.io/zendriver-rs/)
5//! for cache-layout details, offline-mode workflows, and CI integration tips.
6//!
7//! Resolves a [`Distribution`] + [`VersionSpec`] + [`Platform`] triple against
8//! that distribution's index, downloads the matching archive, unpacks it into
9//! an atomic cache layout, and hands back a path to the executable.
10//!
11//! Public entry point is [`Fetcher`]; progress is reported through
12//! [`FetcherProgress`] callbacks tagged with a [`FetcherPhase`].
13//!
14//! ```no_run
15//! # async fn ex() -> Result<(), zendriver_fetcher::FetcherError> {
16//! use zendriver_fetcher::{Fetcher, VersionSpec};
17//!
18//! let chrome = Fetcher::new()
19//!     .version(VersionSpec::Latest)
20//!     .ensure_chrome()
21//!     .await?;
22//! println!("Chrome ready at {}", chrome.display());
23//! # Ok(()) }
24//! ```
25//!
26//! # Distributions
27//!
28//! [`Distribution::default()`] is [`Distribution::ChromeForTesting`], so the
29//! example above fetches exactly what this crate always has. Two further
30//! indexes are available, and *only* resolution differs between them —
31//! download, integrity check, unpack and cache are one shared path:
32//!
33//! | [`Distribution`] | Index | Keyed by |
34//! |---|---|---|
35//! | [`ChromeForTesting`](Distribution::ChromeForTesting) | one [JSON manifest][cft-manifest] | version |
36//! | [`UngoogledChromium`](Distribution::UngoogledChromium) | three GitHub repos, one per OS | version (tag prefix) |
37//! | [`ChromiumSnapshot`](Distribution::ChromiumSnapshot) | a GCS bucket per platform | **revision** |
38//!
39//! ```no_run
40//! # async fn ex() -> Result<(), zendriver_fetcher::FetcherError> {
41//! use zendriver_fetcher::{Distribution, Fetcher, VersionSpec};
42//!
43//! let chromium = Fetcher::new()
44//!     .distribution(Distribution::UngoogledChromium)
45//!     .version(VersionSpec::Explicit("151.0.7922.71".into()))
46//!     .ensure_chrome()
47//!     .await?;
48//! # let _ = chromium; Ok(()) }
49//! ```
50//!
51//! Availability is a per-platform question — the three ungoogled repos
52//! release independently, and the snapshot bucket has no version index at all
53//! — so [`list_builds`] answers it for the platform you actually want instead
54//! of assuming parity.
55//!
56//! [cft-manifest]: https://googlechromelabs.github.io/chrome-for-testing/known-good-versions-with-downloads.json

80/// Lifecycle phase of an in-flight fetch.
81///
82/// Reported via [`FetcherProgress::phase`] so callers can drive a TUI
83/// or log stage-by-stage progress.
84#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash)]
85pub enum FetcherPhase {
86    /// Resolving version + platform against the CFT manifest.
87    Resolving,
88    /// Streaming bytes from the CFT CDN.
89    Downloading,
90    /// Unzipping the downloaded archive.
91    Extracting,
92    /// Verifying integrity (SHA256, executable bit).
93    Verifying,
94    /// All work complete; binary available at the returned path.
95    Done,
96}
97
98/// Progress snapshot emitted by an in-flight fetch.
99#[derive(Debug, Clone)]
100pub struct FetcherProgress {
101    /// Bytes written so far for the current phase.
102    pub downloaded: u64,
103    /// Total bytes expected for the current phase, when known
104    /// (e.g. from the `Content-Length` header during download).
105    pub total: Option<u64>,
106    /// Current phase.
107    pub phase: FetcherPhase,
108}
