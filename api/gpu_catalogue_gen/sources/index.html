Source
Expand description

Where the catalogue’s two inputs come from, and at which commit.

Both are fetched rather than vendored, because both are reachable at an immutable commit SHA. That keeps regeneration reproducible without copying 1.5 MB of pci.ids into the tree or redistributing a dual BSD-3/GPLv2 file.

Pinning against pci-ids.ucw.cz directly is not an option: it serves a moving file with no content-addressed URL, so the catalogue could change with no input in this repo changing. pciutils/pciids is a read-only git mirror of that same database, regenerated automatically, which is what makes a pin possible at all.
