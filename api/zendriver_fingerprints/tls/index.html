Process-wide rustls crypto provider.

reqwest 0.13’s rustls-no-provider installs no provider, so one must be named before any Client is built. Note “before any Client is built”, not “before any HTTPS request”: reqwest constructs its TLS config when the client is created, so even a plain-HTTP request through a fresh client panics without a provider.

This crate keeps its own copy because it depends on neither zendriver nor zendriver-fetcher. All copies are Once-guarded and the first caller wins.
