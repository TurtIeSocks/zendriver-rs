zendriver_fetcher

Module fetcher 

Source
Expand description

Public Fetcher entry point.

Resolves a (distribution, version, platform) triple against that distribution’s index, downloads the archive into a per-build atomic cache layout, unpacks it, and hands back a path to the executable. If the binary is already cached and runnable, returns the path immediately.

Only the first step varies by Distribution. Download, integrity check, unpack, promote and cache-hit detection are one code path for all three — see crate::resolver for the part that differs, and crate::archive for the three packagings it can produce.
