pub async fn list_builds(

Expand description

Builds distribution publishes for platform, newest first.

§Errors

Whatever the distribution’s index fetch returns — including FetcherError::GitHubRateLimited for ungoogled-chromium on an unauthenticated host that has used its 60 requests.

use zendriver_fetcher::{Distribution, Platform, list_builds};

for build in list_builds(Distribution::UngoogledChromium, Platform::MacArm64).await? {
    println!("{}", build.label);
}
