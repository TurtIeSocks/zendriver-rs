Shadow-DOM Turnstile challenge detection.

Dispatches a Runtime.evaluate carrying js::detect_expr, which recursively walks the document plus every shadow root looking for an iframe whose src contains the caller’s iframe_src_contains marker. Returns the iframe’s bounding box (in viewport coordinates) or None.

Run against the page main world: Turnstile lives inside the page’s own frame graph, so an isolated-world context is unnecessary and the lookup must observe the same shadow-DOM mounts as the live page.
